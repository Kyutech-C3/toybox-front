# 作品説明の Markdown

作品詳細、編集画面のプレビュー、ライブモードは同じ表示機能を使います。コメントは通常のテキストです。編集画面の「Markdown の書き方」でも記法を確認できます。

## 対応範囲

- 見出し H1〜H6、段落、行末の半角スペース 2 個またはバックスラッシュによる改行、区切り線
- 太字、斜体、取り消し線、インラインコード
- 箇条書き、番号付きリスト、入れ子、引用
- リンク、参照形式、画像と代替テキスト
- 表と列の文字揃え、表示専用のタスクリスト
- 脚注と本文への戻りリンク
- 見出しへの自動リンク（日本語・重複する見出しにも対応）
- GitHub 形式のアラートと折りたたみ
- コードのハイライト、ファイル名表示、コードのコピー

段落内の普通の改行は表示上つながります。URL だけを書いてもリンクにはならないため、`[表示名](https://example.com)` または `<https://example.com>` と書いてください。外部サイトへのリンクは新しいタブ、ページ内・アプリ内のリンクは現在のタブで開きます。

## 見出しリンク

```markdown
## 使い方

[使い方へ移動](#使い方)
```

見出し横のリンクをクリックすると共有用の URL に移動します。見出し ID は GitHub と同様に英字を小文字、空白をハイフンに変換し、同名の見出しには `-1`、`-2` を付けます。実際の ID には保護用の `user-content-markdown-heading-` が付きます。本文中の短い `#使い方` 形式のリンクは対応する ID へ変換されます。

## コードとファイル名

````markdown
```ts:src/main.ts
const message = "Toybox";
```

```
言語を指定しないテキストもコピーできます。
```
````

ファイル名は言語名の後に `:` で区切って指定します。言語未指定・インデント形式のコードブロックにもコピー操作があります。インラインコードにはコピーボタンを付けません。

## アラート

```markdown
> [!NOTE]
> 補足の内容
```

`NOTE`（補足）、`TIP`（ヒント）、`IMPORTANT`（重要）、`WARNING`（警告）、`CAUTION`（注意）に対応します。通常の引用はそのまま表示します。

## 折りたたみ

```markdown
<details><summary>詳しい使い方</summary>

**Markdown** やリストをここに書けます。

- 手順 1
- 手順 2

</details>
```

本文の前後に空行が必要です。`<details open>` で最初から開いた状態にできます。キーボードの Enter / Space でも開閉できます。

## HTML と未対応の拡張

HTML は Markdown/GFM の表示と折りたたみに必要なタグ・属性に限定してサニタイズします。任意の CSS、イベント属性、script、iframe、SVG は許可しません。画像の HTML によるサイズ指定、下線やマーカーなどの追加装飾も対応範囲外です。

数式、Mermaid、定義リスト、リンクカード、動画や外部サービスの埋め込み、Zenn/Qiita 独自のコンテナ記法、`:smile:` などの絵文字ショートコードは未対応です。Unicode の絵文字はそのまま表示できます。HTML コメントは表示されませんが、秘密情報を書かないでください。
